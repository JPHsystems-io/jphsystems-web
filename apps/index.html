02 / Plugins

Plugins for Agent Zero.

The plugins I wrote and keep working for Agent Zero. All five are MIT licensed and install from GitHub; the OpenRouter Credit Monitor and the 24H Clock are also listed in the official Agent Zero plugin index.

The platform Agent Zero is an open-source agent framework, MIT licensed and maintained by Agent Zero, s.r.o. agent-zero.ai or source on GitHub.

PluginMITindexed

24H Clock

Forces the Agent Zero header clock into 24-hour time — 14:35:07 instead of 2:35:07 PM — and keeps it that way through upgrades.

  • Toggle from the Plugin Hub
  • Lives in usr/plugins/ — an update does not remove it
  • Watches the clock element instead of editing core files
Source on GitHub
PluginMITv1.1.0indexed

OpenRouter Credit Monitor

Shows what is left on your OpenRouter account in the Agent Zero sidebar, so a depleted balance is not a surprise.

  • Low-credit warnings at $5 and $1
  • Optional per-key usage and limits
  • Refresh between 30 seconds and 10 minutes
Source on GitHub
PluginMITv1.2.3

Markdown Memory

One Obsidian-compatible Markdown vault as the memory for every Agent Zero chat — readable in your editor, searchable by the agent.

  • Policy injection plus semantic recall, on local Ollama or cloud embeddings
  • memory_search and memory_reindex tools, also from a remote CLI session
  • Markdown is the source of truth; the SQLite index can be deleted and rebuilt
Source on GitHub
PluginMITv0.0.7

Honcho Shared Memory

Persistent memory on a self-hosted Honcho database, shared by one agent or by several working together.

  • Single-agent and multi-agent modes
  • Stays on your own infrastructure
  • Written with Agent Zero, contributors JPHsystems and Agent Zero
Source on GitHub
PluginMIT

Pushover

Gives the agent exactly one way to send a Pushover notification, and only when you have asked for one.

  • A single pushover_notify tool
  • Token and user key go into the Agent Zero secret store
  • No background hooks: no notification can send itself
Source on GitHub
